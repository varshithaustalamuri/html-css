# HTML and CSS Practice

This is a beginner-friendly HTML and CSS practice project.

## About the Project

This project is created to practice the basic and important features of HTML and CSS.

## Technologies Used

* HTML5
* CSS3

## HTML Features

* Headings
* Paragraphs
* Bold and italic text
* Links
* Images
* Unordered lists
* Ordered lists
* Tables
* Forms
* Input fields
* Radio buttons
* Checkboxes
* Dropdown menu
* Buttons
* Div and sections
* Footer

## CSS Features

* Text colors
* Background colors
* Font size
* Font family
* Text alignment
* Width and height
* Margin
* Padding
* Borders
* Border radius
* Text decoration
* Hover effects
* Button styling
* Table styling

## How to Run

1. Download or clone this project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. The webpage will be displayed.

## Purpose

The purpose of this project is to understand HTML and CSS basics and build a foundation for web development.
